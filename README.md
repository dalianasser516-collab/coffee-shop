# Coffee Shop

A Python console application built while learning and practicing OOP concepts. The program allows the user to choose a coffee shop branch, select an available item from its menu, and complete the payment process.

---

## Features

- Choose between two coffee shop branches
- Display the selected branch menu
- Validate branch selection
- Select an available menu item
- Case-insensitive menu item input
- Validate menu items based on the selected branch
- Display the selected item's price
- Validate payment amount
- Handle invalid payment input
- Confirm the order after successful payment

---

## What this project demonstrates

- **Object-Oriented Programming** - classes, class attributes, instance attributes, static methods, class methods, and dunder methods
- **Basic input handling** - loops and conditional logic
- **Exception handling** - using try/except
- **Input validation** - branch selection, menu items, payment
- **Manual software testing** - applied to a personal project
